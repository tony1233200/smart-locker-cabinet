# Smart Locker Cabinet · 品牌指南（简版）

按 MissCat_AI logo 工作流（先策略后视觉）产出，2026-11-06。

## 1. 品牌策略

- **品牌**：Smart Locker Cabinet（智能借还柜）——开源的自助借还柜服务端：扫码借还共享手持终端（PDA），格口状态大屏实时可见，ESP32 驱动电控锁，零第三方依赖。
- **受众**：仓库/工厂等管理共享设备的团队、开源硬件与嵌入式爱好者。
- **创意方向（定版）**：「格口网格」——一眼是柜子，一格绿色带对勾 = 有设备在位、可借。传达可靠、状态明确。
- **视觉风格**：几何极简、扁平无渐变；避免拟物金属质感、避免通用锁头/钥匙图标（烂大街且与「智能柜」无关）。

## 2. 定稿文件

| 文件 | 用途 |
|---|---|
| `logo.svg` | **主符号**：2×2 格口，右下格绿色对勾。头像、favicon、大屏角标用它 |
| `logo-mono.svg` | 单色版：打印、激光雕刻、单色场景 |
| `logo-monogram.svg` | 备选：SL 首字母 + 绿点，适合小头像位 |
| `logo-lockup.svg` | 横式组合：符号 + SMART LOCKER 字标，README 头图、文档页眉用它 |

SVG 全部可编辑：格口是独立 rect、对勾是 path、字标是 text，改色改字改尺寸直接改对应元素。

## 3. 色彩系统（方案一为定稿，另两套备选）

**方案一 · 柜体蓝（定稿，最专业、社媒友好）**
- 柜体深蓝 Locker Navy `#16324F` — 主色，硬件感、信任感；深色背景上用白色字标
- 格口蓝 Panel Blue `#2A4E74` — 门板层次
- 科技蓝 Signal Blue `#1F7AE5` — 字标强调、链接、按钮
- 在位绿 Ready Green `#21B573` — 「在位/可借」状态色，只用于状态点缀，不大面积铺
- 墨色 Ink `#1B2430` — 正文文字；浅灰 Panel Gray `#EEF2F6` — 浅色背景

**方案二 · 工业橙（备选）**：石墨灰 `#2B2F36` + 工业橙 `#F2762E` + 米白 `#F5F1EA`，更偏机械设备风。
**方案三 · 青绿（备选）**：深青 `#0E4A4F` + 青绿 `#17A398` + 沙色 `#E8DFC8`，更偏物联网风。

## 4. 字体系统

- **Logo 字标**：Montserrat ExtraBold 或 Inter Bold（开源免费商用）
- **标题**：Inter Bold / 思源黑体 Bold（Noto Sans SC， 开源可商用）
- **正文**：Inter Regular / 思源黑体 Regular
- 备选组合：① Poppins + 思源黑体 ② Manrope + 思源黑体 ③ Arial Bold + 微软雅黑（无授权风险环境兜底）

## 5. 自审（资深设计师视角）

- 优点：格口网格与产品本体同构，不看字也知道是柜子；绿色对勾格同时传达「状态系统」；全几何形状，16px 小尺寸仍可辨（已实测渲染）。
- 缺点：2×2 网格在应用图标里较常见，原创性靠「绿格+对勾+门把点」组合区分；B 版 monogram 的 SL 偏通用，只作备选不作主标。
- 用法红线：符号四周留白 ≥ 格口宽度的 1/2；不要拉伸、不要加阴影/渐变、不要把绿格改成其他颜色（绿色是状态语义）；深色背景上用主版即可（深蓝底需加白描边或改用单色反白版时再单独出）。

## 6. 使用场景速查

- GitHub 仓库头像 / README：C 横式组合放 README 顶部，A 符号作仓库社交预览图
- 柜面大屏：A 符号放屏幕角标，与大屏状态绿保持同一色值 `#21B573`
- 文档/幻灯片：页眉用 C，页脚小标用 A
